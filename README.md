# Batch Cooking — vraie application personnelle

Cette application stocke ton profil et tes plans dans `data/user-data.json` sur ton PC. Elle est conçue pour migrer ensuite vers une base en ligne afin de synchroniser PC et téléphone.

## Lancer sur ton PC

1. Ouvre PowerShell dans ce dossier.
2. Tape `npm start`.
3. Ouvre `http://localhost:3000`.

Quand la version hébergée sera prête, tu n'auras plus besoin de faire ces étapes : tu ouvriras simplement un lien depuis le PC ou ton téléphone.
